# 📡 Phone Mirror v2

عرض شاشة الهاتف على المتصفح — بدون USB · بدون برامج · بدون تثبيت

---

## ⚙️ المتطلبات

برنامج واحد فقط:

| البرنامج | الرابط |
|----------|--------|
| **Node.js** (v16+) | https://nodejs.org |

---

## 🚀 خطوات التشغيل

### 1. تثبيت المكتبات

```bash
cd phone-mirror
npm install
```

### 2. تشغيل السيرفر

```bash
node server.js
```

ستظهر:
```
✅ Phone Mirror Server يعمل!
🌐 افتح المتصفح على: http://localhost:3000
```

### 3. الاستخدام

- **صاحب الهاتف:** يفتح الموقع → يختار "أنا صاحب الهاتف" → يضغط "بدء البث" → يرسل رمز الغرفة
- **المشاهد:** يفتح الموقع → يختار "أنا المشاهد" → يدخل الرمز → يرى الشاشة مباشرة

---

## ❓ هل يجب أن يكون السيرفر شغالاً دائماً؟

**نعم** — السيرفر يجب أن يكون شغالاً طالما يستخدم أحد الموقع، لسببين:

1. **Signaling:** يربط الهاتف بالكمبيوتر عند بدء الاتصال
2. **يخدم الموقع:** يرسل ملف index.html للمتصفح

بعد اكتمال الاتصال، البث يصبح مباشراً بين الهاتف والكمبيوتر (P2P) ولا يمر بالسيرفر.

## ☁️ تشغيله على الإنترنت (للاستخدام خارج الشبكة المحلية)

### الخيار 1: Railway (مجاني + سهل)
1. اذهب لـ https://railway.app
2. أنشئ حساباً مجانياً
3. ارفع المشروع وشغّله — سيعطيك رابطاً مثل: `https://phone-mirror.up.railway.app`

### الخيار 2: Render (مجاني)
1. اذهب لـ https://render.com
2. اربطه بـ GitHub ورفع المشروع
3. اختر "Web Service" → سيشغّل تلقائياً

### الخيار 3: VPS (DigitalOcean/Contabo)
```bash
# على السيرفر
git clone <your-repo>
cd phone-mirror
npm install
# شغّله دائماً باستخدام PM2
npm install -g pm2
pm2 start server.js --name phone-mirror
pm2 save
pm2 startup
```

## 🔒 الأمان والخصوصية

- البث **P2P مشفر** بعد الاتصال الأولي
- السيرفر **لا يخزن** أي بيانات
- الغرف **مؤقتة** وتنتهي عند قطع الاتصال
- **HTTPS مطلوب** لمشاركة الشاشة عند النشر على الإنترنت

## 🐛 مشاكل شائعة

| المشكلة | الحل |
|---------|------|
| "مشاركة الشاشة غير مدعومة" | استخدم Chrome أو Edge على الهاتف |
| "تم رفض الإذن" | اضغط "السماح" عند ظهور نافذة الإذن |
| الغرفة غير موجودة | تأكد أن صاحب الهاتف ضغط "بدء البث" أولاً |
| البث لا يظهر على iOS | Safari لا يدعم getDisplayMedia، استخدم الكاميرا بدلاً |
